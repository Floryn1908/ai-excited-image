# The Ocean Stood Up

An original image made to excite make.fun's AI judge: a colossal whale breaching
vertically out of a mirror-calm sea at dawn, arcing high over a tiny lighthouse,
water crowned in golden light, with the line "The ocean stood up." One dominant
shape, impossible scale, and a calm sea that makes the breach feel enormous.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This copies `entry.png` to `out/entry.png` (1024×683, under 1 MiB).
